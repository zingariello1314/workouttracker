# Abs — ce qu’il me manque

Dossier traité : `troisieme dossier gif/abs/`.
Une fiche n’a été créée que si le geste n’existait pas déjà en français ou sous un autre nom.
Les GIF homme/femme, les `v-2` et les petites variantes de prise sont sur la même fiche.
Pour chaque fiche, la description actuelle est un paragraphe d’exécution. Il manque partout la note dense.
