## 🎯 À Propos

**Momentum** est une application web progressive (PWA) conçue pour les passionnés de fitness qui souhaitent suivre leurs entraînements de musculation de manière efficace et motivante. Avec son interface moderne au thème sombre élégant et son logo distinctif, l'application offre une expérience utilisateur exceptionnelle pour planifier, exécuter et analyser vos séances d'entraînement.

### ✨ Points Forts

- 🎨 **Interface Moderne** : Thème sombre élégant avec des gradients colorés et des effets visuels
- 📱 **Responsive Design** : Parfaitement adapté aux mobiles, tablettes et ordinateurs
- 💾 **Stockage Local** : Vos données restent privées et accessibles hors ligne
- 📊 **Analyses Détaillées** : Statistiques complètes et suivi de progression
- 🔄 **Temps Réel** : Interface réactive avec mises à jour instantanées
- 🗂️ **Navigation Complète** : 8 onglets spécialisés pour une expérience optimale

## 🚀 Fonctionnalités Détaillées

### 📅 Onglet "Aujourd'hui"
**Le cœur de votre entraînement quotidien**
- **Navigation Temporelle Avancée** :

  - Détection automatique du jour actuel avec mise en évidence
  - Historique complet accessible d'un clic
- **Système A/B Intelligent** : 
  - Alternance automatique entre semaines A et B
  - Calcul intelligent basé sur la date de début du programme
  - Indicateur visuel de la semaine active
- **Toggle Gym/Maison Contextuel** : 
  - Basculement automatique samedi/dimanche vers exercices maison
  - Adaptation intelligente des exercices selon l'équipement disponible
  - Sauvegarde des préférences par jour

  - Instructions détaillées avec illustrations

- **Feedback de Session Avancé** :
  - Évaluation multi-critères (difficulté, satisfaction, énergie)

## 🛠️ Architecture Technique

### Stack Technologique Moderne
- **React 18.3.1** : 
  - Hooks avancés (useState, useEffect, useContext, useMemo)
  - Composants fonctionnels avec optimisations
  - Context API pour la gestion d'état globale
- **Vite 5.4.10** : 
  - Hot Module Replacement ultra-rapide
  - Build optimisé avec tree-shaking
  - Support TypeScript et JSX natif
- **Tailwind CSS 3.4.14** : 
  - Utility-first avec composants personnalisés
  - Responsive design mobile-first
  - Dark mode natif avec variables CSS

### Gestion des Données
- **Context API Centralisé** :
  - WorkoutContext pour l'état global
  - Hooks personnalisés pour la logique métier
  - Optimisations avec useMemo et useCallback
- **Persistance Locale** :
  - LocalStorage pour les données critiques
  - IndexedDB pour les gros volumes (photos)
  - Synchronisation automatique et backup

### Performance & Optimisation
- **Code Splitting** : Chargement lazy des composants lourds
- **Memoization** : Optimisation des re-rendus React
- **Image Optimization** : Compression et redimensionnement automatiques
- **Bundle Analysis** : Monitoring de la taille des bundles

## 📦 Installation & Déploiement

### Prérequis Système
- **Node.js** 16.0+ (recommandé: 18.0+)
- **npm** 8.0+ ou **yarn** 1.22+
- **Git** pour le versioning

### Installation Complète

1. **Clonage et Setup Initial**
   ```bash
   git clone https://github.com/zingariello1314/workouttracker.git
   cd workouttracker
   npm install
   ```

2. **Configuration Environnement**
   ```bash
   # Copier le fichier d'environnement
   cp .env.example .env.local
   
   # Éditer les variables selon vos besoins
   nano .env.local
   ```

3. **Développement**
   ```bash
   # Serveur de développement avec HMR
   npm run dev
   
   # Linting et formatage
   npm run lint
   npm run format
   ```

4. **Production**
   ```bash
   # Build optimisé
   npm run build
   
   # Test du build local
   npm run preview
   
   # Analyse du bundle
   npm run analyze
   ```

### Déploiement
- **Vercel** : `vercel --prod`
- **Netlify** : `netlify deploy --prod --dir=dist`
- **GitHub Pages** : Configuration automatique avec Actions
