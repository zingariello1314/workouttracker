## 2. Fonctionnement de la matrice

Pour chaque date de la fenêtre :

1. **Résolution lecture seule** du plan (`resolveDayPlanReadOnly`) :
   - snapshot persisté → `planSource=snapshot`
   - sinon perfs → reconstruct → `reconstruct`
   - sinon liste live fournie → `live`
   - sinon → `none`
2. **Métadonnées** : `reliability` + `planKnowledge` (jamais de mélange).
3. **Classification des exercices** selon la source (voir §3).
4. **Canal GTG** séparé (`gtg`, `hasGtgActivity`) — hors dénominateur classique.
5. **Dénominateur** : `usableForAdherenceRate === true` **uniquement** si `planSource === snapshot`.

Agrégat fenêtre `adherenceSnapshotOnly` : taux sur jours snapshot uniquement ; `null` s’il n’y en a aucun.

## 3. Règles de classification

| Situation | Statut | Notes |
| --- | --- | --- |
| Snapshot + coché (+ sets OK ou non structurés) | `realized` | |
| Snapshot + sets structurés &lt; prescrit | `partially_realized` | `partial_sets` |
| Snapshot + reps/sets sans coche | `partially_realized` | `reps_or_sets_without_check` |
| Snapshot + aucun signal | `not_realized` | `gapKind=unchecked` — **pas** « oublié » |
| Snapshot + `suppressedExercises` | `suppressed` | exclu du dénominateur d’adhérence |
| Snapshot + `additionalExercises` / touch hors plan | `supplemental` | déclaré vs `off_plan_touch` |
| Reconstruct | pas de `plannedExercises` | réalisé listé ; plan inconnu |
| Live | `planned` en `indeterminate` | flag `plan_live_not_historical` |
| Vide | `none` | `no_activity_no_snapshot` |

Identité exercice : `originalId` → `storageId` → `id` via `exerciseMatchKey` + `collectCalendarRepKeysForExercise` (variantes A/B).

## 4. Limites non résolues (P3.0)

1. Sur données live oct. 2026 : **0 jour snapshoté** → aucun taux d’adhérence calculable (comportement voulu).
2. Reconstruct ne détecte pas les exercices planifiés non réalisés.
3. Noms d’exercices absents sans `getExerciseNameById` (labels « Exercice inconnu (…) »).
4. Remplacement / déplacement non inférés (P3.1+).
5. Pas de jointure trajectoire (P3.1) ; pas de mix musculaire (P3.2).
6. Aucune écriture de snapshots manquants (P3.3).
