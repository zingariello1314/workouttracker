# Meilleurs mécanismes explicatifs à préserver

## B020 — Décomposition fréquence / contenu

Sur populations compatibles (journées de renforcement), le moteur sépare :

- contribution **fréquence** (jours actifs) ;
- contribution **contenu** (reps / journée active).

En v35 : +1 427 vs −588 alors que le total monte de +17,2 %.  
C’est le modèle de raisonnement à généraliser **quand les données le permettent** — pas une licence pour inventer une cause physiologique.

## B022 — Décomposition par familles de séances

La hausse globale est redistribuée sur les familles (effet fréquence vs contenu par famille).  
Niveau supplémentaire : identifier les **contributeurs réels**, y compris une famille à Δ négatif.

## B013 — Concentration relative (deux dénominateurs)

Comparer :

- part des mouvements ciblés dans leur propre historique large ;
- part du volume total de la fenêtre courte dans le total large.

Le ratio révèle une surreprésentation invisible au total brut.  
À condition de **ne pas** étendre la conclusion à « toute la semaine ».

## B015 — Trajectoires parallèles (homonymes)

Préserver des historiques distincts `ex:…` sous le même intitulé.  
La proximité des volumes doit rester **proportionnée** (M37 : ≤5 % = convergent ; ≤15 % = fourchette).

## Ce qu’il ne faut pas faire

- Multiplier les cartes pour « monter la note ».
- Transformer une association sommeil en sensibilité physiologique.
- Forcer huit récits distincts sur des horizons longs qui partagent le même corpus.
