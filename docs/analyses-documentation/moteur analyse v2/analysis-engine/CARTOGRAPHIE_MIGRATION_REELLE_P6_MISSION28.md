## Adaptateurs legacy

- `insightsFromP6` refuse le fallback legacy si compteurs non reconciliés (M25).
- `recapAdaptiveInsights` conserve un chemin dégradé documenté — ne doit plus produire le catalogue principal.
- Claims générés par `claimFromDiscovery` / wrap : **adaptation conforme** si proof/observedValues réels ; **habillage** si statement seul.

## Lacunes structurantes (Porte B, ordre de valeur)

1. Remonter `recentReps`/`prevReps` structurés depuis les producteurs individuels (pas seulement la prose) — sinon composition retombe sur moyennes.
2. Relations applicables non déclenchées : instrumenter exécution ≠ présence de kind.
3. Producteurs essays/jalons : soit migration minimale (faits+identité), soit réserve documentaire explicite.
4. Mémoire : généraliser aux trajectoires consolidées sans millier de phénomènes artificiels (granularité épisode/thèse).

## Ce que ChatGPT ne doit pas conclure

- « Toutes les cartes ont un claim » ≠ migration analytique.
- « 80 modules non run » ≠ 80 non-exécutions démontrées.
