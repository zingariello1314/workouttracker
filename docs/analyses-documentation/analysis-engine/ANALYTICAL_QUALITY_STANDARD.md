# Norme de qualité analytique

Une analyse **publiable** doit satisfaire tous les critères ci-dessous.  
Une analyse **sélectionnée** doit en plus maximiser la compréhension marginale du pack.

## Critères

| Critère | Exigence |
|---|---|
| Vérité | Chiffres traçables aux événements ; pas de total inventé |
| Exactitude | Unités et dénominateurs corrects (jour actif ≠ séance) |
| Référentiels | Chaque moyenne / % cite sa population |
| Cohérence | Aucune paire d’affirmations incompatibles sans distinction |
| Profondeur | Mécanisme lorsque les données le permettent ; sinon concision |
| Preuves | Faits avant interprétation ; hypothèses marquées |
| Temporalité | Formulations adaptées à l’âge de l’événement et à la période |
| Nouveauté | Pas « nouveau » pour un fait déjà communiqué sans évolution |
| Complémentarité | Apporte un enseignement distinct des cartes déjà choisies |
| Rédaction | Français naturel, accords, noms d’exercices résolus |
| Limites | Incertitudes et tailles d’échantillon assumées |

## Non publiable (exemples)

- Exercice sans séance dans la fenêtre (`empty_window_exercise`)
- Contradiction hard F4 (`per_session_stable_vs_arc_swing`, titre vs chiffres…)
- Nom « un mouvement » / `Exercice NNN` non réparé
- Causalité sommeil/perf sur petit n sans prudence
- Portrait descriptif quand une attribution fiable du même phénomène existe (perd en sélection, pas forcément « mauvaise »)

## Qualité ≠ priorité

- Qualité intrinsèque → éligibilité
- Priorité contextuelle → publication maintenant
