# P3.6 — Habitudes, régularité et découvertes comportementales (conception)

**Date :** 2026-10-31  
**Statut :** conception / préparation — **aucune implémentation**  
**Numérotation :** provisoire mais famille **officielle** (ne pas absorber dans des correctifs mineurs)

---

## 1. Objectif

Publier des constats **simples à lire**, **exigeants à calculer**, sur les habitudes d’entraînement — sans générateur automatique de classements, sans vainqueur forcé, sans confondre absence de preuve et absence d’activité.

---

### À composer (pas de nouvelle vérité physique)

- Proportion d’activité par weekday = actifs / occasions éligibles.  
- Concentration hebdo = part du volume (par unité) sur 1–2 jours vs dispersion.  
- Stabilité remarquable = faible variance sur H long **sans** exiger une nouveauté W.

### Nouvelle opération analytique nécessaire

| Opération | Pourquoi |
| --- | --- |
| Table **weekday × fenêtre** (occasions, actifs, types, couverture) | Les totaux bruts mentent si #lundis ≠ #dimanches |
| Agrégats **exercice × fréquence / exposition** multi-unités | Ledger P3.2a fournit les lignes ; manque le pivot comportemental |
| Détection **égalité / quasi-égalité** weekday | Interdit le vainqueur unique |
| Règles **W/C/H** dédiées habit/stabilité/rupture | Distinctes des trajectoires perf P0 |

**Interdit :** second compteur de reps classic qui divergerait du ledger P3.2a.

## 4. Dimensions séparées (B2)

| Dimension | Définition | Ne pas confondre avec |
| --- | --- | --- |
| Régularité d’activité | Présence d’activité éligible / occasions | Volume ou intensité |
| Quantité de travail | Magnitude **par unité** (reps / s iso / min / km / GTG) | « Intensité physiologique » |
| Fréquence d’exercices | Jours d’exposition ou occurrences canoniques | Volume total |
| Assiduité prouvée au programme | Suivi plan sur jours **proven** seulement | Activité libre hors plan |
| Évolution historique | Δ W vs C, ou rupture vs H | Snapshot unique |
| Stabilité remarquable | Faible dispersion durable sur H | Absence de novelty |
| Caractère inhabituel | Queue de distribution vs H | Simple max de W |
| Concentration semaine | Part du travail sur peu de jours | Fréquence moyenne |

## 5. Jours de semaine (B3)

Pour chaque weekday `d` ∈ {lun…dim} sur une fenêtre :

| Champ | Règle |
| --- | --- |
| `eligibleOccurrences` | Dates calendaires de ce weekday dans la fenêtre (et éventuellement filtrées « données attendues ») |
| `activeOccurrences` | Sous-ensemble avec activité classic et/ou GTG et/ou endurance selon le prédicat déclaré |
| `rate` | `active / eligible` — **jamais** totaux sans occasions |
| `coverage` | Part des occasions avec données exploitables vs trous |
| `activityTypes` | classic / GTG / endurance / mixte / repos prévu / rien |
| `regularityHistory` | Série de rates sur sous-fenêtres H |
| `comparison` | Publier un écart seulement si échantillon min et **marge** vs #2 ≥ seuil ; sinon « quasi-égalité » / non-publication du rang |

## 6. Exercices et volumes (B4)

- Identités canoniques P3.2a / P3.1.  
- Unités **séparées** : reps classiques, séries, jours d’exposition, iso s, lesté documenté, endurance durée/distance, GTG canal propre.  
- **Ne jamais** additionner km + min + reps.  
- GTG synchronisé dans classic : une seule fois (ledger).  
- Homonymes : IDs distincts (déjà P3.3/P3.2a).

## 7. Contextualisation W / C / H (B5)

Pour chaque kind envisagé :

| Élément | Exigence |
| --- | --- |
| **W** | Phénomène mesuré sur la fenêtre courante |
| **C** | Comparaison seulement si comparabilité (durée, couverture, #occasions) |
| **H** | Qualifie nouveauté, stabilité, rareté, rupture |
| Échantillon min | Ex. ≥ 4 occasions weekday ; ≥ 3 semaines pour stabilité |
| Publication | Marge vs second, couverture min, pas seulement « #1 » |
| Non-publication | Quasi-égalité, couverture basse, jour unverified pour assiduité plan, semaine vide, historique incomplet |

Exemples de kinds (provisoires) :

- `disc_habit_weekday_activity_rate`  
- `disc_habit_weekday_work_quantity` (par unité)  
- `disc_habit_weekday_classic_session`  
- `disc_habit_plan_follow_by_weekday` (post-P3.4 / proven only)  
- `disc_habit_exercise_dominant` / `disc_habit_exercise_frequency_shift`  
- `disc_habit_volume_unusual`  
- `disc_habit_stability` / `disc_habit_break`  
- `disc_habit_week_concentration`

## 8. Intégration éditoriale E0 (B6)

- `contentClass` : souvent `descriptive` ou constat utile — **pas** priorité automatique.  
- `discoveryInformativeValue` : ne pas surclasser une trajectoire P0 riche ni un shift musculaire solide.  
- Rivalités explicites :

| Rival | Règle |
| --- | --- |
| Émergence / trajectoires P0 | Même exercice + même histoire → une carte (préférer trajectoire si perf) |
| Fréquence P3.1 | Skip récurrent plan → P3.1 gagne ; P3.6 ne republie pas |
| P3.2b plan×muscle | Anatomie ≠ weekday habit |
| Rythme / calendrier existant | Fusionner ou rivaliser `sameWeekday` / regularity P0 |
| Methodology_limit | Toujours plancher bas |

Une stabilité durable **sans** nouveauté peut être publiée comme constat descriptif pertinent.

## 9. Familles comportementales proposées

1. **Weekday activity** — régularité de présence.  
2. **Weekday work** — quantité par unité.  
3. **Weekday classic ritual** — séances classiques récurrentes.  
4. **Plan adherence by weekday** — dépend P3.3 proven (+ P3.4).  
5. **Exercise habits** — dominance / hausse / baisse de fréquence.  
6. **Unusual volume** — queue vs H, multi-unités.  
7. **Stability & breaks** — habitude stable ou rupture.  
8. **Weekly concentration** — charge concentrée vs dispersée.
