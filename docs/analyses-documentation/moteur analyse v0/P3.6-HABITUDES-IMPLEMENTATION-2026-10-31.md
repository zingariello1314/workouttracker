## D–H. Familles

| Famille | Kind | Publication | Abstention typique |
|---------|------|-------------|-------------------|
| A Régularité | `disc_p36_weekday_regularity` | ≥14 j, ≥3 occ./dow | 7j ; échantillon |

| B Cross | `disc_p36_freq_vs_volume_weekday` | Freq ≠ vol + **anti-pic** ; `strengthClass` | Alignement / pic |
| C Exercice | freq / volume | ≥3 j / part ≥22 % ; hors complementary | Signal faible / égalité |
| D Stabilité | `disc_p36_habit_stability_weeks` | ≥6 semaines pleines, CV≤0,28 | Court / instable |
| E Assiduité | `disc_p36_proven_adherence_weekday` | ≥3 planned proven / dow | Fixture 0 snapshot |

### `strengthClass` (freq × volume)

| Classe | Condition | Lecture éditoriale |
|--------|-----------|-------------------|
| `punctual_limited` | n actif &lt; 3, **chaque** valeur ≥ seuil | Constat limité, pas une habitude |
| `descriptive_tendency` | n ∈ [3,4], médiane sans max ≥ seuil | Tendance descriptive |
| `repeated_habit` | n ≥ 5 | Habitude suffisamment répétée |

**Anti-pic :** si n&lt;3 et `min(valeurs) < seuil`, ou si n≥3 et médiane hors-max &lt; seuil → `load_arm_spike_sensitive` (abstention).

### Dimensions **non** implémentées comme cartes (à ne pas déclarer couvertes)

- Groupe d’exercices régulièrement présents (sans champion)  
- Rupture / reprise d’habitude comportementale dédiée  
- Régularité GTG / endurance par weekday en découverte publiée  
- Causalité révision programme → changement d’habitude  

Le moteur **calcule** des canaux GTG dans les occasions ; il **n’édite** pas de carte GTG-weekday séparée faute de signal honnête sur la fixture.
